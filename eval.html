How accurate is it? Measured, not claimed.

Thirty test submissions, each with a known correct answer, are sent to a live language model with the SubmissionIQ prompt and appetite rules. Every response is scored automatically. The run happens in GitHub Actions and the results below are whatever it produced, including the failures.

How to read this

Unsafe verdicts matter most: a risk returned In Appetite when the correct answer was Refer or Decline. Referring a clean risk costs an underwriter minutes; passing a bad one costs a loss.

Field accuracy checks selected extracted fields per case against the submission. Invented values counts fields the model filled in when the submission did not state them.

Rule accuracy checks that the model cited the rules it should have and none it should not. Several cases sit exactly on a threshold to test this.

Test cases, prompt and scoring code are in the eval folder of the repository. All companies are fictional.
