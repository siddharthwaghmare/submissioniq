Turn a messy broker submission into an underwriting decision in seconds.

Commercial submission intake is one of the most manual steps in insurance — reading broker emails, ACORD forms and loss runs by hand. SubmissionIQ reads the submission, extracts the structured data, flags what's missing, checks it against underwriting appetite, and drafts the broker response.

A portfolio project by Siddharth Waghmare — business analyst, P&C insurance technology. Built to show how a BA designs an AI workflow around a real underwriting process.

AI Analysis

How it works — the BA view›

The problem

Underwriting assistants spend hours re-keying submission data from unstructured broker emails and attachments before an underwriter can even look at a risk. It's slow, error-prone, and inconsistent across teams.

What the AI does

A large language model reads the full submission as free text and returns structured output: extracted fields, a list of material gaps with severity, an appetite verdict scored against an explicit ruleset, and a drafted broker email. The ruleset is deliberately visible and editable — the underwriting team owns the logic, the AI applies it consistently.

Broker submission→ extract→ flag gaps→ appetite check→ drafted response

Impact

Cuts intake triage from ~20–30 minutes to under a minute, standardizes the appetite decision, and pushes a clean, complete risk to the underwriter — or a drafted info request back to the broker — on first touch.

How it was built

Single-page web app. The analysis runs a structured LLM call with the appetite ruleset embedded in the prompt and a strict JSON output contract, then renders the result into an underwriting console. Requirements, data model, prompt design and acceptance criteria defined as a BA deliverable. This hosted version walks through three worked sample submissions end to end, one for each verdict: Refer to Underwriter, Decline and In Appetite.

Demonstration project using fictional companies and sample data. Not affiliated with any insurer. Appetite logic is illustrative. Analyses shown were pre-generated with a language model for these sample submissions; this hosted page replays them and does not call a model live.
